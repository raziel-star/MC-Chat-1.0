## ✨ Overview

**MC-Chat-1.0** is the official Command Line Interface (CLI) application for the specialized **MC-LM-1.0-it** Language Model, offering **expert guidance and seamless conversation** for the entire Minecraft universe. This tool provides instant, accurate answers on crafting, mechanics, and version details, serving as a superior alternative to searching the wiki.

The application is built for deep utility, making it an ideal core component for developers looking to create sophisticated, language-driven **Mineflayer** AI bots and in-game assistants.

### Key Features

* **Minecraft Knowledge Hub:** Get reliable, detailed answers on all game aspects, from Redstone circuits and mob behavior to crafting recipes and biomes.
* **Conversational Fluency:** The underlying model is highly aligned to understand context and maintain conversation flow throughout the session.
* **Unique CLI Experience:** Features a custom terminal interface with **slow-typing emulation** and **color coding** for an enjoyable, modern retro feel.
* **Deployment Ready:** Highly optimized for stability and quick inference on local hardware.

## 🚀 Getting Started

### Prerequisites

* Python 3.8+
* Required Python dependencies (listed in `requirements.txt`).
* The MC-LM-1.0-it model weights.

### 1. Setup

Clone the repository and install the necessary libraries:

```bash
git clone [https://github.com/YourUsername/MC-Chat-1.0.git](https://github.com/YourUsername/MC-Chat-1.0.git)
cd MC-Chat-1.0
pip install -r requirements.txt
```

## 2. Model Weights
Download the MC-LM-1.0-it model weights from Hugging Face and place them in your model directory (e.g., ./models/).
* **[Download MC-LM-1.0-it Weights Here](https://huggingface.co/Raziel1234/MC-LM-1.0-it)**


3. Running the Chatbot
Start the interactive chat session:

```Bash

python inference.py
The chat will prompt you to begin. Type 'exit' or 'quit' to close the application.
```
