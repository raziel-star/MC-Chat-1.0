# MC-Chat-1.0
**MC-Chat-1.0** is the inference solution for MC-LM-1.0-it: a specialized Large Language Model (LLM) fine-tuned on OPT and extensive Minecraft data. It provides fluent, knowledgeable chat (with custom CLI aesthetics!) and deep in-game expertise, making it ideal for creating powerful **Mineflayer** AI agents. Developed by Raziel AI Learning.(me)
